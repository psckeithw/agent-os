# Tech Stack

## Frontend

- **React 18 with TypeScript** – Dynamic UI built with Vite for fast development.
- **Tailwind CSS** – Utility‑first styling.
- **Vite** – Development server and bundler.
- **Responsive Design** – Works on desktop and mobile.

## Backend

- **Node.js with Express** – API server exposing `/api/*` endpoints.
- **TypeScript** – Type‑safe server code.
- **Azure Table Storage** – Persistent storage for snapshots and telemetry.
- **Azure DevOps Integration** – Pulls real‑time metrics and work‑item data.

## Testing

- **Playwright** – End‑to‑end UI and API test suite.

## Other

- **Server‑Sent Events** – Real‑time streaming for health dashboards.
- **Telemetry Service** – Collects and reports health metrics.
- **CI/CD** – Integrated with Azure DevOps pipelines.

## Frontend

- **React 18 with TypeScript**: For building a dynamic and interactive user interface.
- **Tailwind CSS v4**: For modern, utility-first styling.
- **Vite**: For fast and efficient build tooling.
- **Interactive UI**: Includes filterable views, drill-down capabilities, and responsive design.
- **Streaming Responses**: Real-time AI chat powered by Server-Sent Events.

## Backend

- **Node.js with Express**: For building a robust and scalable backend.
- **TypeScript**: Ensures type safety and maintainable code.
- **AI-Powered Chat Assistant**: Provides contextual insights, proactive health summaries, and intelligent recommendations.
- **Real-Time Analytics**: Processes and streams live Azure DevOps data.

## Database

- **PostgreSQL**: Used as the primary database for storing and managing project data. It supports:
  - **Data Models**: Structuring data for API routes and backend services.
  - **Queries and Migrations**: Efficient data retrieval and schema evolution.
  - **Integration Tests**: Validating database interactions during end-to-end testing.
  - **Performance Optimization**: Leveraging indexing and connection pooling for high performance.

## Testing

- **Playwright**: Comprehensive test suite covering API, UI, and data validation.

## Other

- **Azure DevOps Integration**: Seamless connection to Azure DevOps for real-time metrics and insights.
- **AI-Powered Insights**: Automated anomaly detection, risk scoring, and health summaries.
- **Risk Assessment**: Identifies and scores project risks automatically.
